Abstract

This project presents an All-Weather IR-Based Smart Vehicle Gate Recognition System designed to automate vehicle access decisions in gated communities, institutional campuses, and parking facilities while reducing reliance on manual checks. The system couples a weather-aware preprocessing front end with a dual-stage YOLOv8n license plate recognition (LPR) pipeline and a fine-tuned EfficientNet-B4 convolutional neural network for vehicle make and model recognition (VMMR) across 245 distinct vehicle classes. To preserve recognition fidelity under adverse outdoor imaging, three specialized restoration branches are implemented: a Dark Channel Prior–based dehazing pipeline with guided filtering for fog and haze mitigation, a multi-scale vertically oriented median filter with edge-aware protection and Telea inpainting for rain streak suppression, and a LAB-space Contrast Limited Adaptive Histogram Equalization (CLAHE) pipeline for night and low-light enhancement. License plate localization and 38-class alphanumeric character detection are performed by lightweight YOLOv8n detectors trained on Pakistani plate imagery, with deterministic post-processing to assemble region-specific plate tokens. Access authorization is rendered through a dual-modality policy that cross-references the reconstructed license plate text and the predicted vehicle make and model against a registered vehicle database, providing an additional verification layer that resists plate spoofing and plate–vehicle swapping. The complete system is implemented as edge AI on an Orange Pi 5 Pro (16 GB), where all three models run locally on-device through a unified Python inference pipeline fed by a USB camera at the gate lane; recognized plate text, vehicle identity, weather context, and annotated snapshots are transmitted over Wi-Fi to a production React dashboard hosted on Vercel via a secure gate-ingest API. The web platform supports live feed monitoring, event logging, vehicle registration, administrative override, and automated allow/deny gate actions based on registry rules and confidence thresholds, with optional GPIO signaling for physical gate indication. Quantitative evaluation reports 98.07% mAP@50 for license plate detection, 98.07% mAP@50 for character recognition, and 96.24% Top-1 accuracy for vehicle classification on held-out test data, with on-device inference completing in approximately 700–1000 ms per frame on the Orange Pi CPU, demonstrating a fully integrated hardware–software path from adverse-weather image capture through recognition to cloud-audited access control.
