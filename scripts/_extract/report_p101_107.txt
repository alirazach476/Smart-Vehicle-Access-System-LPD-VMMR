6.6 Conclusion          
This All-Weather Smart Vehicle Gate Access System shows how a multimodel AI pipeline can be 
used for automated vehicle detection, classification, and image pre -processing to guarantee high 
accuracy in accessing vehicles. The system outperforms most academic and commercial ALPR 
solutions with a Top1 accuracy rate of 96.24% in v ehicle classification across 245 classes and a 
mAP of 97.7% for character recognition, and a mAP of 98.07% for license plate detection.          
The preprocessing module is equipped with a Dark Channel Prior-based fog removal algorithm and 
a vertical median filter-based rain removal algorithm, which resolves an important issue of existing 
systems by allowing reliable operations under adverse weathe r conditions. The Reactbased web 
dashboard offers a full administrative layer to monitor, log and manage vehicle access.          
The current software implementation is flexible, but the modular architecture is suitable for embedded 
hardware deployment, physical gate integration and real -time video processing. The project lays the 
groundwork for a fully automated, intelligent, scalab le vehicle access control system, which 
significantly cuts down manual monitoring, increases the security level by providing a dual check 
(plate + vehicle model), and provides a thorough digital audit trail.

Appendix C — List of Components          
USB Camera (Gate-Lane Capture)    
• Collects entire vehicle and license plate image at the access gate.    
• FYP deployment: Standard USB 1080p camera via the Orange Pi 5 Pro USB port and batch 
processing of photos and video frames recorded from a laptop is supported.    
Embedded Processing Unit (Orange Pi 5 Pro, 16 GB)    
• Runs the complete edge inference stack:  YOLOv8n plate detection, YOLOv8n character digit 
recognition, and EfficientNet-B4 VMMR locally on CPU.    
• Achieves approximately 700–1000 ms per image, meeting the ≤2 s end-to-end response objective.    
Weather and Light Sensors    
• Design role: Automatically detect rain, fog, and ambient light to trigger the correct preprocessing 
branch.    
• FYP status: Not physically integrated. Weather handling is implemented in software through 
preprocess auto, fog, rain, or night flags, or manual selection based on scene conditions.    
• Future work: Integrate environmental sensors for fully automatic hardware -triggered 
preprocessing.    
Gate Motor / Sliding Gate System    
• Physical mechanism for opening and closing the access barrier.    
• FYP status: Not integrated. The system produces allow/deny decisions in software and logs them 
onto the web dashboard.    \n===== PAGE 104 =====\n 
90    
    
• Future work:  Connect authorization output to a physical gate motor with site -specific safety 
requirements.    
Motor Controller (e.g., Centsys Controller)    
• Interface between the processing unit and the gate motor; converts low-voltage control signals into 
motor drive commands.    
• FYP status:  Not implemented — planned for the next development phase alongside barrier 
hardware.    
Power Supply Unit    
• Provides stable power to the Orange Pi, camera, and peripherals.    
• FYP deployment: 5V 5A USB -C power supply for the Orange Pi 5 Pro under full AI load 
(insufficient current can cause shutdown during inference).    
• Future outdoor deployment:  Regulated PSU relay module, and optional sensors inside a 
weatherproof enclosure.    
Relay Module (Optional GPIO)    
• Provides electrical isolation between the low-voltage Orange Pi GPIO and high-power gate motor 
circuits.    
• FYP status: Optional GPIO/LED indication supported in software for gate open/close status; full 
relay-to-motor wiring is planned, not completed.    
• Improves safety when connecting the Pi to external gate actuation hardware.    
Industrial Enclosure    
• Protects electronics from dust, moisture, heat, and mechanical damage for long -term outdoor 
installation.    
• FYP status:  Prototype demonstrated on a bench/lab setup (Pi + USB camera + monitor); 
weatherproof enclosure is recommended for production but not part of the current prototype.    
Connecting Cables and Wiring    
Hardware Connections:    
• USB camera → Orange Pi USB port    
• 5V 5A USB-C → Orange Pi power input    
• HDMI → monitor (setup and live preview)    
• Onboard Wi-Fi → Vercel cloud upload
